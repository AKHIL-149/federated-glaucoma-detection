# Sample Outputs

This directory contains representative outputs from the Federated Generative AI Framework for Glaucoma Detection.

## Important Note

Due to GitHub repository size constraints, **only sample outputs** are included here (~3 MB). The complete experimental outputs from the original research project total **202 MB** and are not tracked in version control.

## What's Included

### 1. Federated Learning Results (3 files, ~1.7 MB)

**Location**: `federated_learning/`

- **`algorithm_comparison.png`** (414 KB)
  - Comparison of FedAvg vs. FedProx algorithms
  - Shows accuracy, loss, and convergence metrics
  - Demonstrates FedProx's +0.67% accuracy advantage

- **`training_curves_fedavg.png`** (659 KB)
  - Training and validation curves for FedAvg across 50 rounds
  - Illustrates convergence at round 29
  - Peak accuracy: 87.95% at round 40

- **`training_curves_fedprox.png`** (622 KB)
  - Training and validation curves for FedProx
  - Shows faster convergence (round 25 vs. round 29)
  - Demonstrates proximal term effect on stability

**Key Insights**:
- Both algorithms achieve >82% accuracy
- FedProx handles data heterogeneity better
- Convergence occurs within 30 rounds

---

### 2. Multi-Modal Fusion Results (4 files, ~900 KB)

**Location**: `multimodal_fusion/`

- **`confusion_matrix.png`** (78 KB)
  - Final test set confusion matrix (2,350 images)
  - True Positives: 905, True Negatives: 1,088
  - False Positives: 210, False Negatives: 147
  - Accuracy: 84.8%

- **`training_curves.png`** (501 KB)
  - Vision-language fusion training progression
  - 20 epochs of QLoRA fine-tuning
  - Final training loss: 0.023

- **`modality_contributions.png`** (111 KB)
  - Ablation study: Vision-only, Language-only, Fused
  - Vision-only: 81.2%, Language-only: 76.8%
  - **Fused: 84.8%** (+3.6% improvement)

- **`parameter_efficiency.png`** (176 KB)
  - QLoRA parameter breakdown
  - Total: 505,986 parameters
  - Trainable: 176,770 (34.94%)
  - Demonstrates efficiency of LoRA fine-tuning

**Key Insights**:
- Multi-modal fusion provides significant improvement
- Parameter-efficient fine-tuning reduces computational cost
- Vision and language modalities are complementary

### 3. Clinical Explanations (2 files, ~30 KB)

**Location**: `clinical_explanations/`

- **`EyePACS_confidence_distribution.png`** (26 KB)
  - Histogram of prediction confidence across test set
  - 60.4% of predictions have >90% confidence
  - Identifies 5.6% low-confidence cases for expert review

- **`EyePACS_explanation_samples.txt`** (4 KB)
  - Sample clinical reports with uncertainty quantification
  - **First 100 lines only** (truncated from full 22 KB file)
  - Includes diagnosis, probability, confidence, and recommendations

**Sample Report Format**:
```
Patient ID: EyePACS_12345
Diagnosis: Glaucoma suspected
Confidence: 96.8% (High)
Probability: 0.968
Uncertainty: ±0.021

Clinical Findings:
- Enlarged optic cup detected
- Vertical elongation observed
- Peripapillary atrophy present

Recommendation: Refer for comprehensive evaluation
```

**Key Insights**:
- Uncertainty quantification enables safe deferral
- High-confidence predictions (>90%) achieve 94.2% accuracy
- Clinical reports provide interpretability

- Both models generate anatomically plausible fundus images
- Generative augmentation addresses class imbalance

## How to Regenerate Full Outputs

To reproduce the complete 202 MB of experimental outputs:

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Download datasets** (see [../data/dataset_links.txt](../data/dataset_links.txt)):
   - EyePACS-AIROGS-light-V2
   - REFUGE2
   - PAPILA

3. **Run the complete notebook**:
   ```bash
   jupyter notebook notebooks/federated_generative_framework.ipynb
   ```

4. **Execute all 62 cells** (estimated runtime: 9-13 hours on GPU)

5. **Outputs will be saved to**:
   - `outputs/federated_results/`
   - `outputs/multimodal_results/`
   - `outputs/clinical_explanations/`
   - `outputs/generative_results/`
   - And other subdirectories
